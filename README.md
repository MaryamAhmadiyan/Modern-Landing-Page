# Modern Landing Page

A clean, modern, and responsive landing page built with **HTML, CSS, and JavaScript**.

Designed to showcase a modern web layout with a focus on usability, responsive design, and a clean visual experience.

## 🌐 Live Demo

**[View Live Demo](https://maryamahmadiyan.github.io/Modern-Landing-Page/)**

## ✨ Features

- Modern and clean user interface
- Responsive layout for desktop, tablet, and mobile devices
- Interactive mobile hamburger menu with open/close functionality
- Hero section with a call-to-action button
- Features section
- About section
- Services section
- Contact form interface
- Smooth scrolling navigation
- Organized HTML, CSS, and JavaScript files

## 🛠️ Built With

- **HTML5** – Page structure
- **CSS3** – Styling, layouts, and responsive design
- **JavaScript** – Interactive mobile navigation menu

## 🚀 Getting Started

To run this project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/MaryamAhmadiyan/Modern-Landing-Page.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

## 📝 Notes

The contact form is currently a front-end interface and does not submit messages to a backend service.
